## Publishing

The site is dependency-free static HTML. This repository's existing GitHub Pages configuration publishes the repository root from `main` at [sassnarep3-star.github.io/China3](https://sassnarep3-star.github.io/China3/). After changes merge to `main`, GitHub Pages publishes the updated root automatically. GitHub Actions validates local links and source citations on pull requests and pushes to `main`; it does not replace the existing Pages publisher.

## Scope and disclaimer

This is general research, not legal, tax, or individualized banking advice. Foreign-exchange procedures can depend on the account holder's legal identity/status, source and purpose of funds, account bank/branch, transaction classification, and current bank controls. Do not split transactions or use another person's quota. Exact bank rates/fees and personal tax liabilities cannot be determined from the facts provided; the site leaves them blank and flags them rather than guessing.
